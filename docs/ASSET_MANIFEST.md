# Asset Manifest

Every asset this game needs to be finished, specified precisely enough to be
built — procedurally, or commissioned as a GLB, or synthesised — without
further design decisions.

**This is a specification, not the binaries.** No `.glb`, `.png`, `.wav` or
`.mp3` file was authored to produce this document. What is here is the complete
list, with real dimensions, materials, states, and acceptance criteria, so that
each row can be implemented against the existing `registerModel()` pipeline
without anyone having to re-derive what a thing is or how big it is.

Rules that govern every row:

- **Real clinical scale, in metres.** A 13 × 75 mm tube is `0.013 × 0.075`.
  Everything shares one world scale so props can sit next to a full-size arm.
- **Procedural first.** A row is *done* when its procedural builder meets the
  acceptance criteria. A GLB is an upgrade, never a prerequisite —
  `modelRegistry.js` keeps the fallback, and nothing may ship that breaks when a
  GLB is missing.
- **Nothing enters the repository without a row in `docs/ASSET_SOURCES.md`.**
  Source, SPDX licence, redistribution, modification, attribution. No exceptions.
- **Readable at working distance.** Stylised realism. A prop that is
  unrecognisable at the `access` framing has failed regardless of triangle count.
- **Every label is real text.** Generated by `labelTexture.js`, legible at the
  framing where the learner needs it. No lorem, no greeked labels, no
  placeholder brand names.

Status key: **✅** exists and is adequate · **🔶** exists, needs the work named ·
**⬜** does not exist yet.

## 1. Equipment models

All thirteen `supply.*` ids are registered and resolve to procedural builders
(`supplyModels.js`). What is missing is not the models — it is precision on
several, and a `restOffset` on all of them.

### 1.1 Required on every model, currently on none

| Property | Why |
|---|---|
| `restOffset` — `-boundingBox.min.y` of the built template, cached at registration | The step-2 sink-through bug (`REBUILD_PLAN.md` §4.1). Every placement path needs to know how high an object sits on its own base. Derived from the mesh so a GLB swap inherits it. |
| `grabRegions[]` — named sub-volumes with a `contaminates` flag | The correct grip must be the physically obvious one. Assembly already has this implicitly (sheath vs. thread end); it should be data on the model, not coordinates in a runtime. |
| `axis` — the object's own insertion/engagement axis | The 4.0 gesture grammar ("push it home along its own axis") needs this from the model, once. |

## 4. Audio

`audio/procedural.js` synthesises 25 voices and this is the right approach —
they are fed by what the simulation already knows, so sound and model cannot
drift apart. Two buses: `room` ducks, `front` never does.

| `pressureVoice()`, `safetyClack()`, `sharpsDrop()` | ✅ |

| Room tone | ✅ |
| **Thread engagement** — a progressive ratchet ending in a hard stop | ⬜ **new, §4.4 step 4** |
| **Over-torque** — a creak past the stop | ⬜ new |
| **Foam dispenser and running water** | ⬜ new (arrival room) |
| **Paper** — the requisition being picked up, the wristband turned | ⬜ new |
| **Patient speech** | ⬜ **decision needed — see below** |

**Patient speech is the one open question in this section.** Three options:

1. *Non-verbal + caption* — a short vocal utterance plus a text caption.
   Cheapest, ships now, no licensing, no casting, works in every language.
   **Recommended.**
2. *Recorded VO* — real warmth, real cost: casting, direction, ~40 lines ×
   patient variants, re-records for every copy change, and a licence row per
   file.
3. *Synthesised speech* — cheap and uncanny; for a game about putting a needle
   in a person, uncanny is the wrong failure mode.

`lobby.mp3` remains the repository's one **UNVERIFIED** licence. It should be
replaced with a cleared track or removed, not traced. It drives no mechanic.

## 8. What is genuinely missing, ranked

If only five things get built, these five:

1. **Skin that shows depth** (§2). It is what makes palpation perception rather
   than information, and it is the difference between "brilliant graphics" and
   "a clean diagram."
2. **A head that sits on its shoulders** (§2). Currently broken and it costs the
   game its credibility in the first three seconds.
3. **`restOffset` on every model** (§1.1). One property; it is the whole step-2
   bug.
4. **The requisition, the wristband, the sink** (§1.3). Without them, deleting
   step 1 deletes the competency instead of relocating it.
5. **The copy deck** (§6). It is the only way the No-Instructions Test is a test
   rather than a wish.

Everything else on this page is real work, but the game is playable and honest
without it. Without these five it is not.
