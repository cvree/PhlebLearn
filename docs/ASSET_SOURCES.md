# Asset Sources

Every visual asset in Tiny Vials, where it came from, and what we are allowed
to do with it. **Nothing ships without an entry here.**

The rule for this project: an asset is either (a) generated by our own code at
runtime, or (b) an external file with a recorded source, licence, and
attribution requirement. There is no third category.

---

## 3. Adding an external model or texture

Before a `.glb`, image, or audio file enters this repository:

1. **Record the source** — exact URL, author, and the date it was obtained.
2. **Record the licence** — by SPDX identifier where one exists (`CC0-1.0`,
   `CC-BY-4.0`, `MIT`, …), not "free" or "royalty-free".
3. **Confirm redistribution rights.** This repository is public and the build is
   published to GitHub Pages. An asset that may not be redistributed cannot be
   used, regardless of how it is credited.
4. **Confirm modification rights.** Every model gets decimated, re-scaled and
   re-materialled before it ships; a no-derivatives licence disqualifies it.
5. **Record attribution requirements** verbatim, and add the credit to the
   in-app settings panel if the licence requires user-visible attribution.
6. **Optimise before committing** — see `docs/ASSET_PIPELINE.md`. Target: Draco
   or meshopt compressed, ≤ 5k triangles per hand-held prop, ≤ 1024²
   textures, no unused animation tracks.
7. **Add the `url` to the existing `registerModel()` call and keep the
   procedural fallback.** A missing or corrupt file must degrade to the
   procedural build, never to an empty slot or an emoji. This is enforced by
   `modelRegistry.js` and covered by
   `tests/staging.spec.js` → *"a model whose GLB fails to load falls back to its
   procedural build"*.
8. **Add a row to section 2 of this file and to
   `docs/THIRD_PARTY_LICENSES.md`.**

### Style constraints

Assets are only acceptable if they match the existing look: stylised realism —
recognisable silhouettes, flat-ish clinical materials, readable at working
distance, no photoreal detail that fights the rest of the scene. Mixing sources
with different art directions is worse than staying fully procedural.
